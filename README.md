# Network Architecture and Routing Verification

## Overview

This repository contains the configuration outputs and verification information for **Lab**, which focuses on network architecture, router configuration, and routing protocol analysis.

The lab documents the configuration and operational status of three routers:

- R1
- R2
- R3

## Network Topology

The network consists of three interconnected routers configured to exchange routing information and establish end-to-end connectivity.

## Included Documentation

For each router, the following command outputs are provided:

### Configuration
- `show running-config`

### Routing Information
- `show ip route`

### Interface Status
- `show ip interface brief`

### Routing Protocol Information
- `show ip protocols`
